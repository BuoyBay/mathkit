# Provenance

Independent implementation written for this workspace. No third-party source
or downloaded code is incorporated. Algorithms use elementary algebra,
Euclidean gcd, exponentiation by squaring, binary search, series expansion,
Newton refinement, maximum shifting and compensated summation. Built-in Buoy
Math functions supply exp, log, pow, sqrt, floor and ceiling. Public-domain
mathematical identities do not establish conformance or correct rounding.
